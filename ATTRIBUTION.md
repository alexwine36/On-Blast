# Attribution

## Audio

`packages/app-core/assets/audio/sting.wav` is a ~0.4 second musical sting
excerpted from the *Saturday Night Live* "Weekend Update: Mr. On Blast"
sketch (NBC). It is used here as a short excerpt in a free, non-commercial
hobby project, with no affiliation with or endorsement by NBC or SNL.

If you own this material and would prefer it not be used, open an issue and
it will be removed. The audio engine already falls back to a synthesized
sting when the file is absent, so removing it breaks nothing.

`packages/app-core/assets/audio/voice-a4.wav` is a looped vowel from an
original recording by the repository author.
